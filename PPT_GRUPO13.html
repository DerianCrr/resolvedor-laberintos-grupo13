Punto 04 · Evaluación de Alternativas

COMPARATIVA DE 5 ESTRATEGIAS

Prueba real en mapa 40×40 (1,600 celdas)
Alternativa A

Backtracking

Ruta (40×40) 602 pasos
+Poda callejones con visitado
−No garantiza ruta óptima
−Límite de recursión Python
Sin poda: O(b^d) Con poda: O(m·n)
Alternativa B

DFS Iterativo

Ruta (40×40) 166 pasos
+Pila LIFO evita desbordar stack
+Estable en matrices grandes
−Profundiza rama (con rodeos)
Tiempo: O(m·n) Espacio: O(m·n)
Alt. C · Elegida

BFS (Anchura)

Ruta (40×40) 78 (ÓPTIMO)
✓Garantiza camino más corto
✓Cola FIFO deque en O(1)
✓Más rápido (0.8613 ms)
Tiempo: O(m·n) Espacio: O(m·n)
Alternativa D

Dijkstra

Ruta (40×40) 78 (ÓPTIMO)
+Óptimo con pesos variables
−Sobrecarga heapq logarítmica
−5.4544 ms (1,159 nodos)
T: O((m·n) log(m·n)) Espacio: O(m·n)
Alternativa E

A* (A estrella)

Ruta (40×40) 78 (ÓPTIMO)
+Heurística Manhattan h(n)
+Solo 456 nodos explorados
−Mantiene heapq en O(log N)
T: O((m·n) log(m·n)) Espacio: O(m·n)
Punto 05 · Estrategia Principal

¿POR QUÉ BFS (ANCHURA)?

Optimalidad garantizada con costo = 1
Expansión Concéntrica por Niveles

A diferencia de Dijkstra/A* (heapq O(log N)), BFS opera en O(1) amortizado y halla 'E' con pasos mínimos.

4 Estructuras de Datos O(1)
Matriz 2D list[list]
Mapa m × n con 0, 1, 'S', 'E'.
Cola FIFO deque · O(1)
append() y popleft() sin desplazamientos.
Conjunto set · O(1)
visitado bloquea re-exploración y ciclos.
Diccionario padre
Traza padre[(nf,nc)] = actual de E → S.
✓ Garantía Halla el mínimo de pasos si existe ruta; retorna False si está bloqueado.
! Límite Requiere pesos iguales (=1). Con costos distintos usaría Dijkstra / A* (heapq).
Punto 06 · Lógica y Flujo de Control

DISEÑO DE RESOLVER_BFS

Paso 1 / 5
resolver_bfs(maze) 
1. (inicio, fin) ← BuscarInicioFin(maze)
   SI inicio = NULO O fin = NULO → RETORNAR FALSO
2. cola ← deque([inicio]); visitado ← {inicio}
   padre ← {inicio: NULO}; explorados ← 0
3. MIENTRAS cola NO ESTE VACIA:
   actual ← cola.popleft(); explorados += 1
4. SI actual = fin → RETORNAR (VERDADERO, Reconstruir(padre))
   PARA (df, dc) EN [(-1,0),(1,0),(0,-1),(0,1)]:
     si libre y no visitado: marcar, padre y encolar
5. RETORNAR (FALSO, [], explorados) # Cola vacía
Punto 07 · Eficiencia Asintótica

COMPLEJIDAD TEMPORAL Y ESPACIAL

Variables: m = filas, n = columnas
Mejor Caso
Ω(1)

'S' y 'E' adyacentes al inicio (ej. mapa 1×2).

Caso Promedio
O(m·n)

Determinista; explora fracción proporcional de celdas libres.

Peor Caso
O(m·n)

'E' aislada o al extremo: 4·m·n ops + ruta O(m·n).

Espacio Auxiliar
O(m·n)

Hasta m·n tuplas en deque, visitado y padre.

Pruebas de Escalamiento (5 Algoritmos)

Al multiplicar el área por 16× (100 a 1,600 celdas), BFS mantiene el menor tiempo (0.8613 ms) frente a A* (2.0029 ms, 456 nodos) y Dijkstra (5.4544 ms), con ruta óptima de 78 pasos.
